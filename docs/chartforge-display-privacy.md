# AI报表查询执行详情隐藏

Octop 对内置 ChartForge 七个查询工具统一返回安全执行摘要，包括管理员和代看用户的请求。工具卡片、聊天实时推送、历史回放、轨迹详情与导出不再返回 SQL 参数、库表字段元数据、原始结果、数据库异常或原始内容引用。需要 SQL 排障时，在 ChartForge 查询审计按审计编号查找。

实际装载 ChartForge 工具的会话同时隐藏模型思考文字，包括分片的 `<think>` 内容；团队会话包含成员专家的能力。会话保护标记保存在服务端 settings 仓库，断开连接后仍保持隐藏。旧会话按完整调用历史判定，分页和重连不解除隐藏。

模型仍使用原始工具定义、SQL 参数与查询结果；内部归档不改写。其他工具的展示和未启用报表查询的普通对话保持原有行为。

本功能用于避免执行过程直接展示技术细节，并非物理库表结构的保密边界。模型仍可能在最终回答中复述 SQL 或字段名，用户先前导出的文件也不会被收回。若要求真实结构不离开平台，需要另行采用业务查询接口或逻辑数据模型。

不需要数据库升级，不依赖员工自动连接或双向 SSO。已有自动连接草稿分支维持暂缓。
