# AI报表查询连接器

管理员在“连接器”页面的“AI报表查询”卡片中统一设置 ChartForge 平台后端根地址并启用。员工只需点击“连接员工账号”，无需填写 MCP 地址、数据库账号或个人令牌。

本地开发填写 `http://localhost:8080`，不要填写平台前端的 `http://localhost`、`:80`，也不要加 `/sql-gateway` 或 `/mcp/sql` 路径。地址必须与平台 `gateway.base-url` 一致，`localhost` 和 `127.0.0.1` 不能混用。HTTP 需要管理员明确勾选允许内网 HTTP；本机 IPv4 / IPv6 回环地址均支持。

组织配置提供“测试连接”和“检查并保存”。测试只读取 OAuth 元数据，不创建授权或保存配置；启用保存也会先验证地址和端点。填成前端页面、后端未启动、地址不一致和回调未允许会分别显示具体原因，不再返回 JSON 解析异常或笼统的服务器错误。

## OAuth 与身份

在 ChartForge 配置中允许完整回调地址：`http(s)://<Octop地址>/api/connectors/oauth/callback`。连接器卡片的组织配置会显示此地址。反向代理场景请正确配置 Octop 的公共地址与代理头。

配套平台配置默认允许直接访问 Octop 的 `http://127.0.0.1:8088/api/connectors/oauth/callback` 和本地 Vite 的 `http://127.0.0.1:5173/api/connectors/oauth/callback`。实际部署必须设置 `SQL_GATEWAY_OCTOP_CALLBACKS` 为自己的完整回调地址，不使用通配符。配置后需要重启平台；若已设置该环境变量，其内容会覆盖默认列表。

员工连接使用当前页面进入平台授权，失败原因保留在连接器卡片中。平台确认页用中文说明只读权限、数据过滤和撤销方式，点击“同意并连接”后返回 Octop。连接卡片的“平台入口”显示可点击的前端地址、当前工号和连接状态；个人连接计入已启用实例数，失效令牌不会继续显示为有效连接。

前端入口来自平台 OAuth 元数据的 `chartforge_frontend_url`，对应平台 `gateway.frontend-url`。管理员保存连接配置时自动记录此地址。浏览器发起授权使用元数据中的 `authorization_endpoint`，登录、继续授权、确认页和表单提交均走平台前端地址；平台前端需代理 `/oauth2/authorize` 和 `/gateway/oauth/consent`。后端 `base_url` 用于服务端注册、令牌交换和 MCP，仅在管理员配置中填写；前端入口变化不改变令牌的接收地址，也不要求员工重新授权。

Octop 用户名必须是员工工号，与 ChartForge `sys_user.ehr_job_number` 完全一致，按字符串比较并保留前导零。授权后会核对平台 `/gateway/me` 返回的工号，失败时撤销本次令牌。凭据和 OAuth 临时上下文加密保存，不向浏览器返回令牌。

内网 HTTP 需要管理员显式启用。服务端请求只访问配置的精确服务 origin；OAuth 元数据的 issuer、注册和令牌端点必须匹配后端约定路径，浏览器授权端点只允许平台公布的前端地址或兼容旧版的后端地址下的 `/oauth2/authorize`。连接时固定经过检查的 DNS 解析结果，禁止跳转、链路本地地址和元数据服务地址，HTTP 也禁止公网目标。HTTPS 保持证书验证。

员工凭据不可共享或手工覆盖。共享 Agent 的工具每次执行从服务端运行上下文读取当前员工，不捕获配置者身份；查询前自动刷新即将过期的令牌，刷新过程按员工互斥。没有当前员工身份或没有个人授权时拒绝调用。

## 数据工具

统一工具名前缀为 `chartforge_`。支持列出连接、库、表和视图，读取授权字段，执行只读 SQL，列出和执行参数化预设查询。SQL 执行、库表字段权限、记录过滤和审计均由 ChartForge 负责。

每名员工只新增个人授权记录，不新增独立 MCP 进程或数据库连接池。管理员修改服务地址后，原令牌不会发送到新地址，员工需重新授权。

查询请求最长等待 360 秒，与平台的 300 秒数据库执行上限及 330 秒驱动读取超时配合；OAuth 和元数据请求继续使用较短的等待时限。组织反向代理的读取超时也应至少为 360 秒。

完成个人授权或断开连接后会重载运行中 Agent 的连接器，无需重新启动整个 Octop。状态加载失败会显示重试入口；员工身份或平台地址变化后需要重新授权。

## 验证

后端：`uv run pytest tests/unit/connectors/test_chartforge.py tests/unit/connectors/test_catalog_i18n.py tests/unit/i18n -q`。

前端：`cd dashboard && npx tsc -b`，然后按仓库约定构建前端。

本连接器不更改 Octop 登录方式，不自动创建员工账号。ChartForge 配套网关须先安装新增数据库脚本、启用网关配置并部署前端授权页面。
